# fish-ts TSDoc Examples

These examples are authored as TSDoc comments in TypeScript files. Each example
shows the TypeScript source you write and the fish script that fish-ts emits.

## Sections

- [Syntax basics](./syntax-basics.ts): literals, command calls, string escaping, and arithmetic.
- [Variables](./variables.ts): scalar variables, arrays, indexing, and local scope.
- [Control flow](./control-flow.ts): conditions, `if`, `switch`, loops, `break`, and `continue`.
- [Functions](./functions.ts): function declarations, parameters, returns, and calls.
- [Expressions](./expressions.ts): templates, string concatenation, assignments, and mutation.
- [Error handling](./error-handling.ts): `try`, `catch`, `finally`, and return status.

Run `pnpm run docs` to render these topics into `docs/api`.
